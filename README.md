# NLRanalyzer

- NLR analyzer which fetches and mines resistance genes.
- aligns your resistance genes to in-hosted resistance genes from previously published studies.

## New feature
- Neural Network based on the resistance genes for fungal infection using AxonML.
- How to build detail here https://github.com/AutomataNexus/AxonML/tree/main/docs/nn if you know PyTorch.


```
cargo build
```

nlr from identification to deep learning.
